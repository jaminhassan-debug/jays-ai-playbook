## Troubleshooting

**"command not found: bash"**
- Use: `sh DEPLOY_ALL.sh` instead

**"Permission denied"**
- Run: `chmod +x DEPLOY_ALL.sh`
- Then: `bash DEPLOY_ALL.sh`

**Script seems stuck**
- Press Enter if waiting for input
- If issues, check terminal for messages

**Need help during script?**
- Script will show instructions
- All docs available in this folder
- Everything is documented
