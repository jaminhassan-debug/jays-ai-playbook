# Jay's AI Playbook

A comprehensive platform for AI insights, premium prompts, and monetized content.

## Features

- 📚 Article publishing system
- 💰 Product marketplace with Stripe payments
- 🔒 Gated premium prompts
- 📧 Email subscription system
- 🤖 Automated content generation

## Setup

1. Clone the repository
2. Install dependencies: `npm install`
3. Set up environment variables in `.env.local`
4. Run development server: `npm run dev`

## Environment Variables

- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- `STRIPE_SECRET_KEY`
- `NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY`

## Deployment

Deploy to Vercel by connecting your GitHub repository. Set environment variables in Vercel dashboard.
